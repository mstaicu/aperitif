# AGENTS.md

This file is intentionally small. Do not turn it into a README or generated
repo map. Add only non-obvious repo rules, tool gotchas, or repeated agent
failure cases.

- Treat this `k8s/` directory as the working repo root. GitHub workflows are
  intentionally under `k8s/.github`.
- Use Make targets for integration deploy checks: `make deploy-identity`,
  `make deploy-tenancy`, `make deploy-features`, or `make dev`. Do not invent
  ad hoc deployment order.
- Domain units stay separate: `postgres -> migrate -> api/worker`. Do not collapse
  them into one Kubernetes app abstraction.
- Dev overlays using KSOPS require `SOPS_AGE_KEY_FILE` and Kustomize with
  `--enable-alpha-plugins --enable-exec`. Do not replace encrypted Secret
  manifests with plaintext.
- Secrets are scoped per deployable unit even when values match. Keep names
  like `tenancy-api-db`, `tenancy-migrate-db`, and `tenancy-worker-db`
  separate.
- Local Traefik TLS is generated by `make deploy-ingress`. Do not commit developer
  TLS secrets or generated mkcert output.
- Do not restore observability or mesh assumptions unless those platform units
  are explicitly composed into the environment.
- If an instruction here becomes obvious from code, tests, or README updates,
  delete it from this file.
