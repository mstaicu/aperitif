# AGENTS.md

This file is intentionally small. Do not turn it into a README or generated
repo map. Add only non-obvious repo rules, tool gotchas, or repeated agent
failure cases.

- Treat this `k8s/` directory as the working repo root. GitHub workflows live
  under `k8s/.github`.
- Use Make targets for deploy checks. Do not invent ad hoc deployment order.
- Domain units stay separate: `postgres -> migrate -> api/worker/ui`.
- Cross-domain events are versioned current-state facts. Consumers ack stale
  versions.
- If rendered manifests are needed for analysis, sanitize Kubernetes Secret
  payloads before reading or showing output. Replace `Secret.data` values with
  `ZHVtbXk=` and `Secret.stringData` values with `dummy`.
- Keep encrypted Secret manifests encrypted. Do not replace them with plaintext.
- Secrets are scoped per deployable unit even when values match.
- Local Traefik TLS is generated by `make deploy-ingress`. Do not commit
  developer TLS secrets or generated mkcert output.
- If an instruction here becomes obvious from code, tests, or README updates,
  delete it from this file.
