# Production EU

## Bootstrap

```sh
export GITHUB_TOKEN=<github-token>
export SOPS_AGE_KEY_FILE=/path/to/production-age-key
make -C clusters/prod-eu bootstrap
```

- Cluster: current Kubernetes context
- Git: `mstaicu/aperitif`, branch `master`
- Sync path: `k8s/clusters/prod-eu`
- Controllers: source and Kustomize
- Git authentication: read-only SSH deploy key
- SOPS key: cluster-local `Secret/flux-system/sops-age`
- After bootstrap: use Git; do not apply this directory manually

First bootstrap only:

```text
bootstrap
  -> Flux pushes clusters/prod-eu/flux-system to GitHub
  -> git pull --ff-only
  -> add flux-system to kustomization.yaml resources
  -> commit and push
```

## Layout

```text
clusters/prod-eu/
├── flux-system/              generated by bootstrap
├── domains/
│   ├── identity.yaml         Namespace + Flux Kustomizations
│   ├── accounts.yaml         Namespace + Flux Kustomizations
│   └── entitlements.yaml     Namespace + Flux Kustomizations
├── platform.yaml             platform Flux Kustomizations
└── kustomization.yaml        explicit cluster inventory
```

- One domain file: complete production reconciliation topology
- Flux objects: `metadata.namespace: flux-system`
- Component manifests: remain in their component production overlays

## Ownership

```text
root Kustomization/flux-system
├── shared domain Namespaces
└── child Flux Kustomization objects

child Flux Kustomization
└── resources rendered from its spec.path
```

Domain production overlays:

```yaml
namespace: identity # Keep: assigns namespaced resources.

resources:
  # Never include namespace.yaml here.
```

- Root: one owner per shared domain Namespace
- Domain Namespace: `kustomize.toolkit.fluxcd.io/prune: disabled`
- Production leaf: never owns the shared Namespace
- Ephemeral overlay: owns its disposable Namespace
- Platform overlay: owns its exclusive Namespace

Intentional Namespace deletion:

```text
remove workloads
  -> reconcile
  -> remove the Namespace prune annotation
  -> reconcile
  -> remove the Namespace manifest
  -> reconcile
```

## Dependency graph

```text
ingress-crds ──┬──> ingress
               ├──> identity-api
               ├──> identity-ui
               ├──> accounts-api
               └──> entitlements-api

identity-postgres ──> identity-migrations ──┬──> identity-api
                                           └──> identity-cleanup

accounts-postgres ──> accounts-migrations ──┬──> accounts-api
                                            └──> accounts-outbox-publisher
event-bus ─────────────────────────────────────> accounts-outbox-publisher

entitlements-postgres ──> entitlements-migrations ──┬──> entitlements-api
                                                    ├──> entitlements-outbox-publisher
                                                    └──> entitlements-accounts-projector
event-bus ─────────────────────────────────────────────> entitlements-outbox-publisher
event-bus ─────────────────────────────────────────────> entitlements-accounts-projector

observability
```

- `dependsOn`: reconciliation order; not runtime availability
- `ingress-crds`: `prune: false`
- Component leaves: `prune: true`
- Migration Jobs: `force: true`
- NATS timeout: `20m`
- Other timeouts: `5m`
- SOPS decryption: only Kustomizations containing encrypted Secrets

## Release

```text
merge to master
  -> post-merge workflow
  -> ghcr.io/<image>:<git-sha>
  -> ghcr.io/<image>:latest

pin the digest behind latest in the production overlay
  -> commit to master
  -> Flux deploys the image
```

- Flux image automation: not installed
- Post-merge workflows are queued so `latest` follows master merge order
- Future image automation will track and commit the digest behind `latest`
- Database and runtime changes: expand/contract compatible
- Flux ordering: not an atomic multi-component release

## Operate

```sh
flux get kustomizations --all-namespaces
flux reconcile source git flux-system
flux reconcile kustomization <name> --with-source
flux logs --kind=Kustomization --name=<name>
```

## Validate

```sh
kubectl kustomize clusters/prod-eu >/dev/null
```

- Root render: cluster inventory only
- Every referenced `spec.path`: must also render independently
